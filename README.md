# Dress E-Commerce – Frontend

A modern and responsive e-commerce frontend for a dress/fashion store, built with **React**. Users can browse products, view product details, manage their cart and wishlist, and authenticate through the backend API.

## 📌 Features

* 🛍️ Browse dresses and products
* 🔎 View detailed product information
* 🛒 Add products to cart
* ➕ Increase or decrease product quantity
* ❤️ Add/remove products from wishlist
* 🔐 User login and authentication
* 👤 User authentication state management
* 📦 Cart state management with Redux
* 📱 Fully responsive design
* ⚡ API integration with Axios
* 🔒 Protected user functionality
* ❌ Custom 404 / error page

## 🛠️ Tech Stack

* React
* React Router
* Redux Toolkit
* Axios
* Tailwind CSS
* JavaScript
* Vite
